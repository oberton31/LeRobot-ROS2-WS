When starting recording script, it will automatically start the first episode. Hit r to say redo this episode, then reset the robot, and press r to start for real. WHen done recording episode hit n. Then reset robot. Then hit n again to start the next episode

When resetting the robot, note that due to some limitations, the robot will not be respawned at the original pose. Instead, manually use the commands to revert it to its original position.
